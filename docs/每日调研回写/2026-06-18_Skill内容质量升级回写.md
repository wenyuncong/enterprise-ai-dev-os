# 2026-06-18 Skill 内容质量升级回写

## 触发原因

上一轮方法论清洗后，`scripts/py/audit_methodology.py` 仍报告 33 个 `SKILL_STRUCTURE` warning。用户要求继续做“Skill 内容质量升级”。

## 现场判断

审计发现的问题分两类：

1. 真实质量问题：23 个 core/governance Skill 缺少 YAML frontmatter，影响跨工具发现和触发。
2. 审计规则偏粗：Skill 创建规范要求 `description` 承载触发语义，因此不能只在正文中查找 `When to use` 字样。

## 本轮动作

- 为 23 个 core/governance Skill 增加 `name` 和高信号 `description`。
- 将审计脚本升级为 frontmatter-aware。
- 对 5 个技术 Skill 补强触发描述、工作流或护栏。
- 将 `skills/SKILL_MANIFEST.json` 中 38 个正式 Skill 成熟度标为 `verified`。
- 生成验收报告：`docs/测试验收报告/2026-06-18_Skill内容质量升级验收.md`。
