# 方法论操作资产与场景回归

日期：2026-07-28

## 完成本批

1. 建立技能职责矩阵，规定每个交付阶段只有一个主责技能，避免路由、规划、拆分、架构、验证和发布治理重复接管。
2. 建立全 AI 产品交付任务包。产品负责人只提供产品结果、示例、优先级、易用性和业务流程验收；AI 根据项目证据补齐定位、真相、批次、安全和验证。
3. 增加方法论场景回归脚本。它会验证完整规则样例可通过审计，并验证缺失“安全修改/精准定位”约束的样例会被拒绝。

## 关键边界

- 职责矩阵只澄清主责，不覆盖项目专属规则。
- 任务包不要求产品负责人理解代码文件、数据库或框架。
- 场景回归使用临时目录，不修改真实项目或正式方法论资产。
