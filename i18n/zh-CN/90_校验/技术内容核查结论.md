## 3. 撤回或降级：我上一轮说过头的 8 条

| 上一轮的说法 | 回到上下文后的核对结果 | 裁定 |
|---|---|---|
| `flutter-animations`「Rule 要求 300ms 以内，示例却用 2 秒/1 秒，自相矛盾」 | 规则原文是 **"Keep animation durations under 300ms **for UI feedback**"**，有明确范围限定；L86/L131 的 1 秒、2 秒示例属装饰性与序列动画 | **撤回** |
| `springboot-patterns`「限流按 `getRemoteAddr()` 取 IP，反代下取到代理 IP」 | 文档自己在 **L250-278** 专门讲了 `ForwardedHeaderFilter`，并写明「Without this configuration, `request.getRemoteAddr()` returns the proxy IP, not the client IP」——**文档已覆盖该风险** | **撤回** |
| `springboot-patterns`「`Thread.sleep` 退避在非阻塞栈上会阻塞线程」 | 该 Skill 面向 Spring MVC / JPA / 事务 / 缓存（非 WebFlux）。在 servlet 线程上这是常见简化 | **降级**为「若用于 WebFlux 等响应式栈，需改为非阻塞退避」 |
| `multi-stage-dockerfile`「`NODE_ENV=production` 写法错，应为 `ENV NODE_ENV=production`」 | L53 是**散文建议**（"Set appropriate environment variables like NODE_ENV=production"），不是 Dockerfile 指令 | **降级**为「示例里可补一行 `ENV NODE_ENV=production`」 |
| `tailwind-design-system`「写入十六进制颜色字面量，与『不要硬编码颜色』自相矛盾」 | 该字面量在 `meta[name="theme-color"]` 的更新代码里（L692-695）。这个 meta **必须**用字面量，浏览器不解析 `var()` | **撤回**（建议文档补一句「meta theme-color 属例外」） |
| `tailwind-design-system`「Consider OKLCH 与 Use OKLCH 强度不一致」 | 一处是**迁移检查清单**（面向既有项目），一处是新项目指南 | **降级**为措辞差异，非错误 |
| `docker-expert`「Rule 要求锁定基础镜像版本，示例却用浮动标签，自相矛盾」 | Rule 原文是 `Pin base image versions`；示例用 `node:18-alpine` 而非 `latest`，符合「锁定主版本」的常见含义 | **撤回**（真正的点只是 Node 18 已 EOL，见第 2 节） |
| `vue`「声明基于 3.5 却劝退 Reactive Props Destructure，与官方冲突」 | 该 Skill 源自上游 vuejs-ai，是**偏好性**建议（团队可自选），不是事实错误 | **降级**为口径差异 |

> 另有 1 条上一轮的细节需要更正：我把「`tailwind-design-system` 的 `Don't use arbitrary values` 与示例自违」列为矛盾——`@utility` 里写具体值是**定义自定义工具类**的正常写法，与「标记里不要用 arbitrary value」并不冲突。**撤回**。
