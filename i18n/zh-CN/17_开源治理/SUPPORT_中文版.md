## 问题与讨论 | Questions And Discussions

使用 GitHub Discussions 处理：

- 使用问题
- 工具兼容性报告

- 迁移经验
- 适配器验证说明

建议的讨论分类：

- Announcements
- Q&A
- Ideas
- Tool Compatibility
- Showcase

## Issues

使用 GitHub Issues 处理：

- 可复现的缺陷
- 文档错误
- 适配器路径更正
- 审计脚本失败
- 缺失或损坏的检查
